# 📖 Glossary · Glossário

| Term | Plain words · Em palavras simples |
|---|---|
| **Query plan · Plano de execução** | The recipe PostgreSQL chooses to answer your query. `EXPLAIN` shows it. · A "receita" que o PostgreSQL escolhe. O `EXPLAIN` mostra. |
| **`EXPLAIN`** | Shows the plan *without* running the query. · Mostra o plano *sem* executar. |
| **`EXPLAIN ANALYZE`** | Runs the query for real and adds actual times and row counts. Careful with `INSERT/UPDATE/DELETE`: they really run. · Executa de verdade e mostra tempos reais. Cuidado com `INSERT/UPDATE/DELETE`. |
| **`BUFFERS`** | How many 8 kB pages were read (`shared hit` = from memory cache, `read` = from disk). Fewer is better. · Quantas páginas de 8 kB foram lidas. |
| **Seq Scan** | Reads the whole table row by row. Fine for small tables or when you need most rows. · Lê a tabela inteira. |
| **Parallel Seq Scan** | Seq Scan split among several workers. · Seq Scan dividido entre vários processos. |
| **Index Scan** | Walks an index to find rows, then fetches them from the table. · Usa o índice para achar as linhas. |
| **Bitmap Index Scan / Bitmap Heap Scan** | First collects *where* the matches are (bitmap), then reads those table pages in order. Good for a moderate number of rows. · Primeiro marca *onde* estão as linhas, depois lê essas páginas em ordem. |
| **Nested Loop** | For each row on one side, look up matches on the other. Great when the lookup is indexed. · Para cada linha de um lado, busca no outro. |
| **Anti Join** | Keeps rows that have **no** match on the other side (what `NOT EXISTS` becomes). Can stop at the first match found. · Mantém linhas **sem** correspondência. |
| **Correlated subquery · Subconsulta correlacionada** | A subquery that uses a column from the outer query, so it may run once per outer row. · Subconsulta que usa coluna da consulta externa. |
| **`loops`** | How many times a plan node ran. Multiply the per-loop time by it. 100,000 loops in scenario 02. · Quantas vezes o nó rodou. |
| **`cost`** | PostgreSQL's *estimate*, in arbitrary units. Not milliseconds. · Estimativa em unidades arbitrárias. |
| **`rows` estimated vs actual** | If they differ a lot, statistics are stale: run `ANALYZE`. · Se divergem muito, rode `ANALYZE`. |
| **Index · Índice** | A separate sorted structure that lets the database find rows without reading the whole table. Costs disk space and slows writes. · Estrutura separada e ordenada; custa espaço e deixa escritas mais lentas. |
| **B-tree** | The default index type. Good for `=`, `<`, `>`, `BETWEEN`, `ORDER BY`. · Tipo padrão. |
| **Foreign key (FK) · Chave estrangeira** | A column that points to another table's key (`loans.member_id → members.id`). It guarantees consistency but is **not** indexed automatically. · Coluna que aponta para a chave de outra tabela; não ganha índice sozinha. |
| **Partial index · Índice parcial** | An index over only the rows matching a `WHERE`. Tiny and fast for "hot" subsets. · Índice só das linhas que satisfazem um `WHERE`. |
| **GIN** | Index type for values containing many items (words, trigrams, arrays, JSON). · Índice para valores com vários itens. |
| **Trigram · Trigrama** | A 3-character slice of text (`"cat"` → `"  c"`, `" ca"`, `"cat"`, `"at "`). `pg_trgm` indexes these so `'%word%'` can use an index. · Pedaço de 3 caracteres. |
| **`pg_trgm`** | The extension that provides trigram functions and operator classes (`gin_trgm_ops`). · A extensão que fornece trigramas. |
| **`ANALYZE`** | Refreshes the table statistics the planner relies on. · Atualiza as estatísticas usadas pelo planejador. |
| **Warm cache · Cache quente** | Data already in memory. The lab measures warm cache; a cold start would be slower. · Dados já em memória. |
| **Median · Mediana** | The middle value of the runs. Less sensitive to a single slow outlier than the average. · Valor do meio; resiste a um valor fora da curva. |
| **Speed-up** | before ÷ after. 91.6 ms → 0.3 ms ≈ 300x. · antes ÷ depois. |
| **Synthetic data · Dados sintéticos** | Fake data generated by `generate_series` and `random()`, with a fixed seed so results are repeatable. · Dados gerados, com semente fixa. |
